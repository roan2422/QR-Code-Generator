# QR Code Generator

## Installation

1. Download the ZIP file.
2. Extract the ZIP contents.

## Usage

1. Open `index.html`.
2. Ready to use.

## Compatibility

This tool works on **desktop browsers** when opened directly as a local file.  
On **mobile devices**, local HTML files may not load scripts or images correctly.

To use it on a phone, you must connect to a **Live Server running on your desktop**  
(e.g., via VS Code Live Server or any local web server).
